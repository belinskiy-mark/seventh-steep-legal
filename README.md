# seventhsteep.com

Static site for the Seventh Steep iOS app, served by GitHub Pages from `main` `/` (legacy build, no Jekyll).

## Layout

| Path | What | Edited by |
|---|---|---|
| `privacy/`, `support/` (4 languages each) | Legal pages linked from the app and App Store Connect | by hand only; the build never touches them |
| `index.html`, `guides/**`, `sitemap.xml`, `robots.txt` | Marketing pages | generated by `tools/build.py` |
| `assets/` | CSS, self-hosted fonts as WOFF2 subsets (OFL licences next to them), images | by hand |
| `src/data/tea-profiles.json` | Copy of `pur-pur/data/tea-profiles.json` (the app's brewing numbers) | copy from the app repo |
| `tools/og.html`, `tools/make-og.sh` | Source and renderer of `assets/img/og.png` | by hand |

## Build

```sh
python3 -I tools/build.py          # writes the generated pages
python3 -I tools/build.py --check  # exit 1 if a generated page is out of date
```

Python 3 standard library only. Commit the generated HTML: GitHub Pages serves the files as they are.

Refresh the brewing numbers after a change in the app:

```sh
cp ../pur-pur/data/tea-profiles.json src/data/tea-profiles.json && python3 -I tools/build.py
```

## Fonts

The WOFF2 files are subsets of the app's TTF files (`pur-pur/App/Resources/Fonts`): Latin, Latin-1, Latin Extended-A, Cyrillic (with Ґ ґ) and common punctuation. Made with fonttools in a throwaway venv (not a site dependency):

```sh
pyftsubset CormorantGaramond-Medium.ttf --unicodes="U+0020-007E,U+00A0-00FF,U+0100-017F,U+0218-021B,U+0400-045F,U+0490-0491,U+2010-2027,U+2030-203A,U+2044,U+20AC,U+2116,U+2122,U+2212" --layout-features='*' --flavor=woff2 --output-file=CormorantGaramond-Medium.woff2
```

Same for `Onest-Regular` and `Onest-SemiBold`; `NotoSerifSC-Brand` with `--unicodes='*'` (it holds only 七 第 泡). A character outside the subset falls back to the next font in the CSS stack.

## Notes

- `PROVIDER_TOKEN` at the top of `tools/build.py` comes from the App Store Connect campaign link generator. Campaign data shows in App Store Connect only after 5 or more downloads per campaign.
- Links inside pages are relative, so the site works both at `belinskiy-mark.github.io/seventh-steep-legal/` and at `seventhsteep.com/`. Canonical, Open Graph and sitemap URLs use `https://seventhsteep.com`.
- App Store campaigns: `site-home`, `site-guides`, `guide-shou`, `guide-sheng-young`.
